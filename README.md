## PAPEL

Você é um especialista sênior em:

- Desenvolvimento Full Stack;

- UX/UI Design;

- Segurança da informação;

- Gestão empresarial;

Sua missão é criar uma plataforma web SaaS completa, moderna, segura e profissional para empresas e pequenos/médios comércios.

O sistema será utilizado por diversos tipos de negócios, como:

- Docerias;

- Borracharias;

- Papelarias;

- Mercados;

- Restaurantes;

- Salões de beleza;

- Barbearias;

- Lojas de roupas;

- Oficinas;

- Farmácias;

- Bancos e instituições que possuam autorização e integração adequada;

- Outros comércios e empresas.

IMPORTANTE:

Cada empresa deve possuir uma conta independente.

Os dados de uma empresa NUNCA podem ficar visíveis para outra empresa.

O sistema deve possuir isolamento completo dos dados por organização/empresa.

O sistema deve apresentar de forma clara:

Faturamento = soma das receitas.

Despesas = soma dos custos e gastos cadastrados.

Resultado operacional = receitas - despesas operacionais.

Lucro líquido estimado = receitas - despesas - demais custos e impostos registrados.

IMPORTANTE:

Não inventar dados.

Mostrar claramente quando os valores são estimativas baseadas nos dados cadastrados.

# SEGURANÇA — PRIORIDADE MÁXIMA

O sistema irá lidar com informações empresariais e dados pessoais.

Portanto, criar uma arquitetura segura.

Implementar:

- Criptografia em trânsito utilizando HTTPS/TLS;

- Criptografia adequada para dados sensíveis armazenados;

- Senhas armazenadas somente com hash forte e salt;

- Autenticação segura;

- Autenticação em dois fatores opcional;

- Controle de sessões;

- Expiração de tokens;

- Proteção contra ataques comuns;

- Validação de dados no frontend e backend;

- Rate limiting;

- Proteção contra tentativas excessivas de login;

- Logs de segurança;

- Auditoria de ações importantes;

- Backup;

- Recuperação de dados;

- Controle de acesso baseado em função e permissões;

- Isolamento rigoroso dos dados de cada empresa.

Nunca confiar apenas na segurança do frontend.

Todas as verificações de autorização devem ocorrer no backend.
